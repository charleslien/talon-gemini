## Installation
1. Clone this repo:
```
git clone https://github.com/charleslien/talon-gemini.git ~/.talon/user/talon-gemini
```
2. Install dependencies
```
~/.talon/bin/pip install -r ~/.talon/user/talon-gemini/requirements.txt
```
3. Get your Gemini API key from https://aistudio.google.com/app/apikey
4. Put the API key in `gemini_api_key`
```
echo {api_key_here} > ~/.talon/gemini_api_key
```
